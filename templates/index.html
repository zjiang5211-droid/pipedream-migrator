FAQ

What exactly do I upload?

In Pipedream, open your project's Settings, choose Export Workflows, and download the ZIP. Upload that ZIP here — or a single workflow JSON. The file is parsed in memory and never stored.

What does the $29 pack unlock?

Full n8n JSON downloads for every workflow plus a bulk ZIP with the migration checklist as Markdown. The inventory, checklist and n8n previews are free forever. Details →

Do you see my API keys or OAuth tokens?

No. Pipedream's export replaces anything credential-like with <redacted>, and we never ask for tokens. You reconnect your own accounts inside n8n.

Will the n8n JSON import cleanly?

It's generated in n8n's public workflow format (nodes + connections) and imports via n8n's import. Every code step carries your original code with a review flag; app actions become the matching n8n node with your original settings preserved in notes. Review before relying on it — the checklist tells you what to check.
